# item-0022 extract inventory r1 -- mechanical, no fidelity claim

Generated by `dossier/item-0022-workpapers/extract-inventory.py` (Lane B of the
item-0033 Phase 2a apply). Deterministic and dependency-free; two runs over an
unchanged extract set produce a byte-identical file.

**This is an inventory. It carries no verdict, no fidelity claim and no
disposition recommendation.** No PDF was opened. No hash is booked. No extract
is edited. Grading the extracts against their primary sources is Phase 2b, and
the counts below exist to say how large that pass is.

**Why the extracts need a grade at all.** Their content is transcribed from
anchored primary sources, but their selection and section structure are
indexed to three reports that were dropped as objects on 2026-07-27, and some
assertions are sourced to the item-0022 kickoff dispatch, an ephemeral object
that no longer exists in any form. Neither clean nor worthless; ungraded.

**Quotation discipline.** Naming a report-indexed heading names a defect; it
does not restate a claim. Heading matches are quoted whole, because the
heading text is itself the finding. Every other match quotes the matched
phrase only, never the sentence around it. No content of any dropped report
appears here. Quoted text is ASCII-folded; a non-ASCII character is rendered
as its code point.

## Axes

| axis | what is counted |
| --- | --- |
| I1 | headings or annotations framing content as a dropped report's claim |
| I2 | assertions sourced to the item-0022 kickoff dispatch or another ephemeral object |
| I3 | occurrences of report 1 / report 2 / report 3 outside I1 and I2 |
| I4 | in-tree cross-references, which survive and are not defects |
| I5 | total lines, and lines inside display or code fences |

Axis membership is disjoint by construction: a span claimed by I1 or I2 is
excluded from I3. I4 is counted independently of the other three, since an
in-tree path may legitimately appear inside a report-indexed heading.

**What I2 mechanically counts, stated precisely.** Every reference to an
ephemeral object, in either direction. Most are an assertion resting on the
kickoff dispatch. Some are the opposite -- a disclaimer that an operator-held
document was NOT used as evidence. Both are counted, and neither is graded
here: a disclaimer is still a place where the extract's provenance chain
passes through an object no session can open, which is what Phase 2b has to
decide about. The per-extract listings below show which kind each match is.
