== S2. Decision frame ==
Growth classes (expo(F) = ln F / lnln x, F = (ln x)^expo):
  GC-CONST : expo bounded in x with a stated finite limit
             ("exponential in the rank alone": cost <= c^k).
  GC-ITLOG : expo = c * lnlnln x + O(1), c > 0 ("rank times an
             iterated logarithm": cost = (c' ln k)^k).
  GC-FASTER: expo / lnlnln x -> infinity.
BET-20260725-11 resolution clause, verbatim:
  "operator judgment against the item-0028 sheet; a favourable
  outcome requires the loss to be exponential in the rank alone,
  not in rank times an iterated logarithm"
Item body, two-numbers criterion, verbatim:
  "Two numbers decide it. If the class-restricted loss is
  exponential in the rank alone, the cost exponent collapses and
  the polylog gate becomes a live question rather than a settled
  failure. If the loss is the same, the hypothesis is closed by
  arithmetic."
