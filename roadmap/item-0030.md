Measurement, not proof work, and independent of the other two successors.

The literature-grain search produced one anchor that clears the rank and
window axes jointly. Everything separating it from the project's target is
two named things: the Hardy-Littlewood variant it assumes, and the grain.
That converts an open-ended distance into a measurable one, and nobody has
measured it.

What to produce: the assumed hypothesis stated on named axes (admissible
tuple rank, admissible shift range, error term, uniformity in each), set
against the corresponding parameters of the hypotheses this project already
carries, and against the weaker variants in the anchored shelf. The useful
output is not a verdict but a table someone can argue with.

The second question, worth the same session: whether any weakening of that
hypothesis still clears rank and window jointly. If the clearance is robust
under weakening, the hypothesis axis is softer than it looks; if it is
brittle, that is equally worth knowing before any route is built on it.

No web access is needed. The anchor is extracted and booked, and the
comparison targets are all on the shelf.
